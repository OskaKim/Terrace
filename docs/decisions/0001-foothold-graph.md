# 0001 マップはタイルではなく足場(線分)のグラフで表す

- 日付: 2026-09-04

## 背景

手本はメイプルストーリーの横スクロール。坂道、段差、崖、はしごとロープ、上下に重なった足場がある。

## 決定

- 地面や床は線分(`Foothold`)の連なり。線分の端は `PrevId` / `NextId` で隣の線分に繋がり、0 なら崖
- はしご・ポータル・湧き点も座標を持つオブジェクトとして同じマップに置く
- 物理エンジンは使わない。移動は Map の問い合わせ API(真下の足場、線分上の Y、隣の足場)だけで組む
- マップは構造データなので、マスタ(CSV)ではなく JSON で持つ

## 理由

- 坂道が線形補間だけで表せ、タイルの段差のようなガタつきが無い
- 「崖から歩き出すと落ちる」「↓+ジャンプで下の足場へ」などのジャンルの手触りを、繋がりの有無で素直に書ける
- 物理エンジンに頼らないので、Client と Server で同じ判定を純 C# で持てる([ADR 0003](0003-pure-csharp-rules.md))

## 引き換えにしたもの

- 足場の繋がりを手で書く必要がある。書き間違いは `Validate()` で機械的に見つける
- タイルマップ用の既存エディタが使えない(マップエディタは未着手)

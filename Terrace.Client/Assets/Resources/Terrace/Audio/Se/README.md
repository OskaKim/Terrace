# 効果音

パックから使う音だけを複製してある。どれも CC0 1.0(個人・商用を問わず利用でき、クレジット表記は任意)。
どの音をどのきっかけで鳴らすかは `Assets/Terrace/Runtime/Unity/AudioLibrary.cs` の対応表にだけ書く。
取り込み設定(読み込み時に展開)は `Assets/Terrace/Editor/AudioImportProcessor.cs` が自動で付ける。

# BGM

パックから使う曲だけを、名前を付け替えて複製してある。どれも CC0 1.0(個人・商用を問わず利用でき、クレジット表記は任意)。
どのマップでどの曲を流すかはマップ JSON の `bgm` が決める(値はこのフォルダからの相対パス、拡張子なし)。
取り込み設定(ストリーミングで読む)は `Assets/Terrace/Editor/AudioImportProcessor.cs` が自動で付ける。

| exploration3_thael_mines.ogg | Exploration3 - Tha'el Mines | 同上 | 同上 |
